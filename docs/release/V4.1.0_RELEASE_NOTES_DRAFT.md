# Release Notes — AIKA Optimizer V4.1.0 (rascunho)

> Documento de trabalho para a fase de release. Versão promovida para
> `V4.1.0` no gate de build candidate (ainda não publicada).

## Principais mudanças em relação à V4.0

- **Renderizador dgVoodoo2:** novo módulo que permite ao cliente AIKA
  (DirectX 9) usar DirectX 11 como backend gráfico, com perfis
  Performance / Balanced / Quality e modo AUTO (seleção conforme o hardware
  detectado).
- **Cores das Pedras:** nova ferramenta para gerenciar o perfil de cores das
  pedras do cliente (`itemlist6_color_profile.json`).
- **Central de Ajuda:** nova central de ajuda integrada, com navegação por
  categoria.
- **Cliente AIKA configurável:** caminho do cliente validado e configurável,
  com detecção por executáveis/estrutura reconhecidos.
- **Injetor e Organizador de Sets:** melhorias nos modos SETS/ARMAS, fallback
  de peças por família/classe e organização/conversão de assets.
- **Prioridade multi-instância:** aplicação de prioridade aos executáveis do
  AIKA reconhecidos.
- **Hardening de restauração:** snapshot/DNS/rollback e ponte IFEO/PerfOptions
  com adoção segura do legado V4.0.
- **Segurança:** política de restauração mais conservadora e adoção segura de
  backups legados.
- **Game Booster conservador:** classificação de processos com proteção de
  processos críticos e nunca encerrando processos UNKNOWN.
- **Plano de energia:** fallback seguro de desempenho máximo.
- **Melhorias visuais/responsivas e correções gerais.**

## Compatibilidade

A V4.1 mantém compatibilidade com configurações e backups suportados da
V4.0, adotando uma política de restauração mais conservadora.

## Pendências antes do release estável

- Build PyInstaller real e execução do EXE.
- Instalação Inno Setup, teste de instalação limpa, upgrade e uninstall.
- Divulgação do build final e hash na página de Releases.
